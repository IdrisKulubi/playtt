# VenueEdge replacement PC

Use when the venue Windows PC is replaced but the venue, NVRs, and PlayTT resources remain the same.

## Prepare

1. Create a replace-host pairing session from `/nvr`.
2. Download the current signed installer if the replacement PC is clean.

## Install

1. Install VenueEdge on the replacement PC.
2. Enroll with the pairing code at `/nvr`.
3. Complete local NVR and camera setup on the new host.

## Verify

- Installation appears online with the same venue assignment.
- Commissioning and config application succeed.
- Replay capture works for at least one mapped resource.
